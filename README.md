# 認証団体データベース 業務フロー試作版

寄付の受け皿となる認証団体データベースについて、業務の流れ（更新申請 → 承認 → 更新管理 → 検索・抽出 → 寄付サイト反映）を画面で試せる検討用の試作版です。

- 団体名・数値・メールアドレスはすべて架空です。
- ブラウザ内だけで動き、データはどこにも送信・保存されません（再読み込みや「初期データに戻す」で初期状態に戻ります）。
- メール送信や外部連携は行いません（画面上の状態とログが変わるだけです）。

## 使い方（タブ）

1. **更新申請（団体）**：団体を選ぶと登録済みの値が入ったフォームが開き、修正して提出すると「承認待ち」になります。
2. **承認（財団）**：申請ごとに現在値と申請値の差分を確認し、承認（団体マスタへ反映）または理由付きで差戻しします。
3. **更新管理**：全団体の更新状況（未依頼・未回答・不達・再連絡など）を一覧し、更新依頼や再連絡を記録します。
4. **検索・抽出**：テーマ・地域・予算などで絞り込み、件数・地方別グラフ・一覧を表示し、CSVをコピーできます。
5. **寄付サイト反映**：前回反映以降に公開項目が変わった団体だけを、公開項目のみのCSVで確認し「反映済み」を記録します。
6. **一括登録**：Excel（.xlsx／.xls）やCSVのファイル、または「見本データで試す」で複数団体をまとめて読み込みます。行ごとに OK／要確認／エラー を判定し、取り込んだ行は承認待ちに入ります（ファイルはブラウザ内だけで処理）。

画面右側（スマホでは下）の「通知・操作ログ」に操作の記録が表示されます。

## ローカルでの開き方

`index.html` をブラウザで開くだけで動きます（サーバー不要。フォントを Google Fonts から、Excel読み込み用の部品 SheetJS を cdnjs から読み込みます。SheetJS が読めない環境でも CSV は使えます）。
